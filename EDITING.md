# How to update the Timpanogos Invitational website

This is for the person who keeps the site up to date. **You don't need to know how to code.**
You'll use a simple web page with fill-in-the-blank forms.

---

## First time only

You need a free GitHub account, and the meet's website owner needs to add you as an editor.

1. Make a GitHub account at **https://github.com/join** (free).
2. Tell the website owner your GitHub username. They'll send you an invite — click the link in
   the email to accept it.

That's a one-time thing. After that, you just log in whenever you want to make a change.

---

## Making a change

1. Go to **https://bdme132.github.io/timpanogos-invitational/admin/**
2. Click **Sign in with GitHub** (enter your GitHub login if it asks).
3. You'll see the content sections in a menu. Pick what you want to change:

   | Section | What it controls |
   |---------|------------------|
   | **News & Announcements** | Posts that show in the News section. Add, edit, or delete posts. |
   | **Meet Details** | Date, time, location, fees, registration links, contact info, the stats bar, and the "About" text. |
   | **Race Day Schedule** | The AM and PM session event times. |
   | **Course Records** | The boys' and girls' course record holders. |
   | **Champions** | The year-by-year individual and team champion tables. |
   | **Notable Alumni** | The alumni cards. |
   | **Past Results Archive** | The list of year links in the Results section. |

4. Edit the fields, then click **Save** / **Publish**.
5. Wait about a minute, then refresh the live site —
   **https://bdme132.github.io/timpanogos-invitational/** — to see your change.

---

## Tips

- **Writing a news post?** Set **Date** to the day it should appear (newest posts show first).
  Leave **Draft** off to publish it; turn **Draft** on to hide it while you work on it.
- **Updating the meet for a new year?** Open **Meet Details** and change the Year, dates,
  registration links, and fees. The countdown clock uses the "Race Date (ISO)" field, so set that
  too.
- **Nothing breaks if you make a mistake** — every change is saved in history and can be undone by
  the website owner. If something looks wrong, don't panic; just contact them.
- If the live site doesn't update after a few minutes, it's usually still rebuilding — give it a
  little longer and refresh again.
